JARVIS Lite - OPPO A3s

Android 8.1 / 2 GB RAM / 16 GB storage के लिए lightweight base project.

Features:
- Hindi voice input
- Text-to-Speech
- समय बताना
- Battery percentage
- YouTube खोलना

Build: ZIP extract करें और Android Studio में project खोलें। Gradle sync के बाद Run करें।
फोन में Developer Options और USB Debugging चालू रखें।

नोट: यह ChatGPT जैसा full AI model नहीं है; यह lightweight voice-assistant base है।
